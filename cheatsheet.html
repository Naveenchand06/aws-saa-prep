SAA-C03 Decision Cheatsheet

Discriminators only. Which service, which tier, what it costs. EC2 and VPC deep-dives excluded — those appear as one-liners in section 9.

Cheapest Middle Priciest Trap

Find the adjective first — cheapest / least overhead / lowest latency / survives a Region failure — then pick the service that owns it. Two options are usually both correct; one matches the adjective.

Prices: approx us-east-1, per GB-month. Learn the order, not the digits.

Most repeated distinction on the exam. Multi-AZ = sync standby, auto failover, not readable. Read replica = async, readable, manual promotion. Global = survives Region loss.

5. Migration & transfer

Every question reduces to: how much data, how much bandwidth, how much downtime, does the engine change.

ServiceMovesChoose when
DMSDatabasesCDC keeps target in sync → near-zero downtime.
SCTSchemaOnly when the engine changes. Same engine → DMS alone.
MGNWhole servers → EC2Default "rehost 200 VMs" answer.
Elastic Disaster RecoveryServers, for DRSame tech as MGN, ongoing.
DataSyncNFS, SMB, HDFS, objectsOnline, scheduled, verified. When the network can cope.
Snow familyBulk offlineWhen the network can't.
Storage GatewayOngoing hybrid accessFile (NFS/SMB+cache), Volume (iSCSI), Tape (VTL for existing backup software).
Transfer FamilySFTP/FTPS into S3Partners keep their clients; you run no servers.
Application Discovery ServicePre-migration inventoryRight-size before moving. Compute Optimizer does it after.
AWS BackupCentral backup policyEBS, RDS, DynamoDB, EFS, FSx + cross-Region copy.

Ship or stream? days ≈ TB ÷ (10.8 × Gbps). 100 TB over 1 Gbps ≈ 10 days. 80 TB over 100 Mbps ≈ 2.5 months → Snowball. 500 TB over 10 Gbps ≈ 5 days → DataSync.

Rule: more than a week on the wire → ship a device. Snowcone 8–14 TB · Snowball Edge ~80 TB · Snowmobile 100 PB (retired, still a distractor).

10. Traps for experienced people

Where real-world instinct points the wrong way.

InstinctExam wants
Build it on EC2, you know howThe managed service. Your competence isn't the criterion — the adjective is.
Multi-AZ to scale readsStandby is invisible. Read replicas scale reads.
NAT for private AWS API callsVPC endpoints. Gateway ones are free.
Glacier is always cheapest90/180-day minimums and 128 KB floor can make it dearer.
Standard-IA for "infrequent"If the pattern is unknown, Intelligent-Tiering.
Sticky sessions fix session lossExternalize to ElastiCache/DynamoDB.
SNS for reliable delivery to one consumerSQS. SNS→SQS when several need a copy.
Security groups have deny rulesAllow-only and stateful. NACLs are stateless with deny.
One NAT gateway is fineIt's zonal. One per AZ.
Kinesis for any queueOne consumer, no replay → SQS is simpler and cheaper.
Spot saves money anywhereNever for a stateful primary database.

65 questions / 130 minutes = 2 min each. Pass ~720/1000. Multi-response states how many to pick; no partial credit.

Eliminate, don't recall. Two options are obviously wrong; the last two differ by one adjective from section 1.
